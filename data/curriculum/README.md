# StudySprint — First and second year curriculum mapping

Checked: 21 November 2026. Source: https://uktech.ac.in/en/page/syllabus

## What is included

- One common first-year source: separate Sem I and II tables plus Biotechnology bridge-course conditions.
- 21 separate main B.Tech branch entries: both Sem III and IV mapped for each.
- Two separately labelled archival second-year branches: Petroleum Engineering and Bio Chemical Engineering (2019–20).
- Eight optional specialization source links, kept separate from degree branches.
- 558 source-table entries across the common first year, main branches and two archives. This is a count of mapped rows, including repeated/shared offerings and alternative groups, not unique subjects.
- Course codes, titles, category/type, printed credits, original row cells where available, official PDF page links and explicit review flags.

Open `StudySprint-Year1-Year2-Branch-Map.pdf` for the readable report. Use the CSV for filtering and the JSON for an importer. Give the AI editor `AI-EDITOR-PROMPT.md` together with the catalog and source register.

## Scope and status

This is a researched curriculum-table mapping and implementation brief. No changes have been made to the live StudySprint site or GitHub repository by this research pack. Unit-by-unit teaching content, lab exercise lists, worked solutions and quizzes are not extracted or generated in this pack. The official source PDFs remain the authority for those details. Their links are included for every branch.

The 21 branch entries are from the university's main B.Tech listing, not a verified list of programmes offered by RIT. First-year subject pairs need the college's actual semester allocation. Aeronautical's 2025–26 document starts at second year, so its first-year applicability is explicitly pending confirmation. The common first-year PDF is for admissions from 2022–23 onward; older batches require their own scheme.

Do not activate all slash-separated alternatives in one semester. Some internship rows refer to summer work assessed in a later semester. Optional/minor rows are choices, not mandatory extra courses for everyone. The eight optional specialization documents refer to a 2021–22 batch scheme; confirm applicability before enabling them.

CIA1/CIA2 unit coverage, dates and paper patterns are college-specific and remain unconfigured. CSE++ is a college alias whose official mapping is not confirmed here. Existing user-reported exam scope is not assumed to apply to all students.

## Source issues preserved for review

- EEE's linked document contains an EE draft heading; do not auto-approve equivalence to EE.
- CSE Semester IV contains an ambiguous credit cell for Technical Communication/UHV.
- Biotechnology prints CST009 for Cyber Security and GB04 for General Proficiency; these need review.
- ECE has an incomplete alternative code pair and a repeated proficiency code.
- Plastic & Polymer prints PPP007 for both a theory and a lab row.
- Some subjects have different titles under a shared code across branches. Identity must include the source curriculum version.
- The two 2019–20 branch sources are archival, not claimed to be current replacements.

The JSON retains raw evidence and flags instead of guessing corrected values. CSE(Cyber Security)'s borderless scheme tables were transcribed separately from their own document. No syllabus is assigned to a different branch merely because the branch names look similar.
